## W-07. Сторінка «Про автора»

Семантична розмітка це використання HTML-тегів, назви яких описують роль елемента на сторінці: `header`, `nav`, `main`, `footer` тощо. Вона краща за безликі `div`, бо браузери, пошукові системи й програми екранного читання розуміють структуру сторінки. Також такий код легше читати й підтримувати, а стилі потім підключати за зрозумілими класами.

Використані теги: `html`, `head`, `meta`, `title`, `body`, `header`, `nav`, `main`, `section`, `article`, `footer`, `figure`, `figcaption`, `img`, `h1`, `h2`, `p`, `strong`, `em`, `ul`, `li`, `table`, `thead`, `tbody`, `tr`, `th`, `td`, `a`, `span`, `div`.


## W-10. Flexbox, адаптивність і форма

`flex-wrap: wrap` дозволяє flex-елементам переноситися на новий рядок, коли вони не вміщаються в одному ряду. Без нього елементи стискалися б або виходили за межі контейнера. Наприклад, у шапці меню перескакує під логотип на вузькому екрані.

Медіа-запит потрібен, щоб застосовувати окремі стилі за певних умов, зокрема для вузьких екранів телефона (`max-width: 600px`). Завдяки йому поля форми складаються в колонку, а кнопка розтягується на всю ширину.

Атрибут `name` потрібен серверу: за ним Flask читатиме значення полів після відправки форми. Атрибут `id` потрібен JavaScript і елементу `label` (через `for`), щоб знаходити конкретне поле на сторінці.

## W-12. TaskBoard оживає: JavaScript і DOM

У цій лабораторній роботі було додано інтерактивність до вебзастосунку TaskBoard за допомогою JavaScript та DOM.

### Реалізований функціонал

1. Додавання нових задач через HTML-форму без перезавантаження сторінки.
2. Перевірка введення назви задачі. Порожня назва не допускається.
3. Вибір пріоритету: низький, середній або високий.
4. Додавання терміну виконання та опису задачі.
5. Відображення задач у вигляді окремих елементів списку.
6. Позначення задач як виконаних за допомогою прапорця.
7. Видалення задач.
8. Відображення загальної кількості задач і кількості виконаних.
9. Збереження даних у localStorage браузера, що дозволяє відновлювати задачі після оновлення сторінки.

### Використані технології

- HTML5 — структура сторінки та форма.
- CSS3 — оформлення карток задач і адаптивність.
- JavaScript — обробка подій та логіка застосунку.
- DOM — створення та оновлення HTML-елементів.
- localStorage — локальне збереження задач.

### Основні функції JavaScript

| Функція | Призначення |
|---|---|
| `nextId()` | Генерує унікальний ідентифікатор задачі |
| `loadTasks()` | Завантажує задачі з localStorage |
| `saveTasks()` | Зберігає задачі в localStorage |
| `createTaskElement()` | Створює HTML-елемент задачі |
| `render()` | Оновлює список задач і лічильник |

### Налагодження та перевірка

| Перевірка | Очікуваний результат |
|---|---|
| Додавання задачі | Нова задача з'являється у списку |
| Порожня назва | Відображається повідомлення про помилку |
| Позначення виконання | Задача перекреслюється |
| Видалення задачі | Задача зникає зі списку |
| Оновлення сторінки | Раніше додані задачі зберігаються |
| Перевірка консолі браузера | Відсутні помилки JavaScript |

### Висновок

Під час виконання лабораторної роботи було вдосконалено вебзастосунок TaskBoard. За допомогою JavaScript реалізовано інтерактивну роботу із задачами, обробку подій, маніпуляції DOM та збереження даних у localStorage. Перевірено додавання, видалення, позначення виконаних задач і збереження інформації після оновлення сторінки.
